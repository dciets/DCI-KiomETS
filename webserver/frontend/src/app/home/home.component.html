Instructions

Vous devez concevoir un agent autonome - sans interaction humaines durant l'exécution - pour capturer le plus de territoire que possible. Le jeu est séparé en rondes. Au fil des rondes, votre agent accumule des points.

Pour rouler l'agent, veuillez l'enregistrer.

  1. Inscription
  2. Entrez votre nom d'agent
  3. Notez votre ID d'agent

Ensuite, vous pouvez rouler l'agent comme ceci :

Python : python main.py [votre ID de d'agent] "[nom de votre agent]"

JS : npm run serve [votre ID de d'agent] "[nom de votre agent]"

You must create an autonomous agent - without human interaction during the execution - to capture the most territories. The game is split in rounds. Each rounds, you agent cumulate points.

To run your agent, you must first register it.

  1. Inscription
  2. Enter your agent's name
  3. Save your agent's ID

Then you can run it with this

Python : python main.py [your agent's ID] "[your agent's name]"

JS : npm run serve [your agent's ID] "[your agent's name]"

Régles du jeu

Game's rules

Terrains

Les terrains sont essentiels, sans eux, votre agent meurt. Chaque terrain peut avoir l'un des deux bâtiments suivants :

  • L'usine - permet d'automatiquement fabriquer des soldats
  • La barricade - permet de mieux defendre un terrain ayant une garnison (des soldats sur place)

En plus du bénéfice multiplicatif aux soldats, les barrières requièrent aussi 5 soldats minimum à capturer lorsqu'elle possède une garnison (5 + garnison * multiplicateur). La force d'une barrière se calcul comme suit : nb defenseur * 3 + 5. La force de tout autre terrain se calcul comme suit : nb defenseur * 2. Il faut au minimum un soldat de plus que la force du terrain pour le capturer.

Un terrain peut ne pas avoir de bâtiment. Il est soit vide, soit en construction. Un terrain est en construction lorsqu'un bâtiment est en cours de construction ou de destruction. À partir d'un terrain non vide, votre agent doit détruire le bâtiment courant avant de lancer la construction d'un autre bâtiment.

Pour changer le type de bâtiment d'un terrain, il faut envoyer l'une des deux actions suivantes :

create_build_factory_action()/createBuildFactoryAction() pour créer un/e usine.

create_build_barricade_action()/createBuildBarricadeAction() pour créer une barricade.

Pour démolir un bâtiment, il faut envoyer l'action suivante :

create_demolish_action()/createDemolishAction().

Toutes ces actions nécessite l'ID d'un terrain en paramètre.

Terrains

Terrains are essentials. Without them, your agent dies. Each terrain can have one of two buildings :

  • The factory - automatically create soldiers
  • The barricade - offer better defensive value to a garrisoned terrain (a terrain with soldier in it)

While giving a multiplicative bonus to soldier, barriers also requires 5 soldiers at a minimum to capture when garrisoned (5 + garrison * multiplier). The power of a barrier is computed as such : nb defender * 3 + 5. The power of other terrains are computed as such : nb defender * 2. You need a minimum of one soldier more than a terrain force to capture it.

A terrain can have no building on it. It is either empty or in construction. A terrain is in construction when a building is being build or destroyed. If a terrain is not empty, you must destroy the current building then launch the construction of another building.

To change the building type of a terrain, you need to send one of the two following action :

create_build_factory_action()/createBuildFactoryAction() to create a factory.

create_build_barricade_action()/createBuildBarricadeAction() to create a barricade.

To destroy a building, you need to send the following command :

create_demolish_action()/createDemolishAction().

All these actions require a valid terrain ID in parameter.

Soldats

Les soldats servent à defendre et à attaquer. Un soldat sur un terrain sert de garnison. Chaque soldat en garnison possède la force de 2 soldats, sauf s'il se trouve sur une barrière. Dans ce cas il possède la force de 3 soldats.

Les soldats peuvent être déplacé en envoyant une create_move_action()/createMoveAction(). L'action prend en paramètre l'ID du terrain de départ, l'ID du terrain de destination ainsi que la quantité de soldat à envoyer. Les terrains doivent être adjacents et le terrain source doit avoir la quantité requise de soldat pour être valide.

Si deux groupes de soldats se rencontre entre les terrains. Un combat à force égale - 1 soldat = 1 force pour les deux agents - se produira. Si plusieurs groupes de soldats appartenant à plusieurs agents attaquent un terrain, tous les groupes combineront leur force pour battre le defenseur. Ensuite, chaque agent combat, à force égale, combat l'ensemble des autres agents. Si un groupe survit, il prend possession du terrain. Si aucun groupe ne survit, le defenseur garde le contrôle du terrain.

Soldiers

The soldiers are there to defend and attack. A soldier on a terrain is considered a garrison. Each soldier in garrison have the power of 2 soldiers, except on barriers. In this case, it possesses the power of 3 soldiers.

Soldiers can be moved with the create_move_action()/createMoveAction(). The action takes as parameters the source terrain ID, the destination terrain ID and the quantity of soldiers to send. Both terrains must be adjacent and the source terrain must have enough soldier for the action to be valid.

If two groups of soldiers meet in between terrais, an equal power battle - 1 soldier = 1 power for both agent - occurs. If multiples groups of soldiers belonging to multiple agents attack a terrain, all groups will combine their power to beat the defender. Then, each agent fights, at equal power, all the other agents. If a group survives, it takes possession of the terrain. Otherwise, the defender keep the possession of the terrain.

Actions

Chaque terrain peut envoyer une seule action par update. Pour envoyer une action au serveur de jeu, il faut retourner un array, dans la méthode update de l'agent, contenant le retour de fonction d'une des fonctions d'action.

Actions

Each terrain can receive only one action per update. To send an action to the game server, you need to return an array, in the update method of the agent, containing the return value of an action function.

Calcul des points

À la fin de chaque ronde, chaque agent reçoit son nombre de territoire en points plus cinq fois son nombre de kill. Un kill est effectué lorsqu'un agent capture le dernier territoire d'un autre agent.

Points counting

At the end of a round, each agent receive the number of territories in points plus five time his amount of kill. A kill is done when an agent capture the last terrain of another agent.
