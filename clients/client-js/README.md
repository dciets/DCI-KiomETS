# Comment rouler l'agent

Dans `env.js`, mettez l'IP du serveur de jeu - non celui du site web (les deux peuvent être le même) au champ `_host`.

Installez les dépendances : `npm install`

`npm run serve [votre ID d'agent] [votre nom d'agent]`

# How to run the agent

In `env.js`, add the game server IP - not the website IP (both can be the same) at the `_host` field.

Install dependencies : `npm install`

`npm run serve [your agent's ID] [your agent's name]`
